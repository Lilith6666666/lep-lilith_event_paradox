The Library's named-entity title scanner is adapted from src/library.js,
including upstream's capitalization, sentence-boundary, punctuation and minor-
word treatment. Its bounded candidate tracking and card prompts are based on
upstream's plot-relevant card creation/update design. LEP replaces
multi-Continue card generation with a structured sidecar on normal generation,
adds classification, strict parsing, ownership and a separate Entity Registry.
Upstream LSIv2/eval, Notes-based storage, extra config/data cards, destructive
commands and memory-bank compression are not included in this focused subset.
No standalone Auto-Cards installation is needed. This is not an upstream release.
The full permission notice is also embedded in Library.js so pasted copies
retain the license. The rest of LEP is not attributed to LewdLeah.

Event Paradox v0.5 — optional modified Inner Self integration

Inner Self by LewdLeah
Official repository: https://github.com/LewdLeah/Inner-Self
Pinned upstream revision: 297a1a04c0e11b41f69e3e57a607b47eee34334b
Upstream version: v1.0.2
Retrieved: 3 October 2026 from the official upstream main branch.

This is a modified derivative bundled with LEP: Lilith Event Paradox, NOT an official
upstream Inner Self release. Inner Self's optional Auto-Cards install/integration
path, bundled implementation, creator settings, config option, /AC activation,
uninstaller and delegation are removed because LEP already provides
the sole Auto-Cards/entity subsystem. The remaining Inner Self behavior/settings
are intended to remain upstream-compatible.

Compatibility changes scope upstream globals, prefer explicit hook selection,
rescan new cards rather than assume a return shape, isolate console/paused cycles
and filter their history, and separate guide/debug/thought metadata from EP
narrative. Long output bypass is removed so thought instructions are still
parsed. EP renders authored prose last. Thought labels/debug screens accompany
only normal model prose, never authored EP scenes. Source hashes, modifications,
and the full patch are recorded in vendor/inner-self. The complete license below
also accompanies the bundled code and vendor/inner-self/LICENSE.
